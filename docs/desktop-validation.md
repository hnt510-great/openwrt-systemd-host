[desktop setup](desktop.md) and [GNOME architecture](gnome-desktop.md).

Use these records for observed results and their exact scope:

- [GNOME VM validation](gnome-desktop-validation.md): session, application input,
  RDP/Moonlight, audio, reconnects, reboot persistence and router smoke checks.
- [Physical deployment](gnome-desktop-deployment-20261028.md): signed package
  installation, physical GPU/remote checks and configuration preservation.
- [TLS and Files](gnome-tls-files-validation.md).
- [GNOME Tweaks](gnome-tweaks-validation.md).

These are dated results. Documentation cleanup does not constitute a new
image build, VM run, physical deployment or device reboot.
